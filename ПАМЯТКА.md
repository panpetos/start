# Памятка «что где лежит» — psytalk.pro

Навигатор по проекту для будущих сессий. Не деплоится (нет в `deploy-ftp.yml`) —
это внутренний справочник. Общие правила (ветка, деплой, соглашения по коду,
секреты) — в `CLAUDE.md`; здесь — карта «фича → файл → функция».

> Актуально на 2026-09-17. Правишь фичу — обнови строку тут.

## Как устроено в целом
- **Фронт** — статические `*.html` в корне + модули в `js/`. Общая шапка/подвал —
  `js/layout.js` (`psyWriteHeader()`, `psyWriteFooter()`).
- **API** — самостоятельные PHP-файлы в `api/`. Каждый подключает `config.php`
  (+ `db.php` через резолвер `getDB/getDbConnection/getPDO`), всё в try/catch,
  `CREATE TABLE IF NOT EXISTS` для своих таблиц. Настройки — только через
  `psySetting()` из `api/settings_lib.php` (колонки на проде `k`/`v`).
- **Деплой** — push в `claude/psytalk-pro-dev-onsqnt` → GitHub Actions
  (`.github/workflows/deploy-ftp.yml`) заливает по SFTP **только явно
  перечисленные** файлы. Новый файл — добавь строку `put ...`.
- **SEO-страница поста** — `/post.php?id=<id>` (серверный рендер мета/OG/JSON-LD).

| `api/rtc_lib.php` | `rtcSendDm($pdo,$from,$to,$content,$read=false)` — вставка личного сообщения. |
| `api/notify_lib.php` | диспетчер уведомлений. |

| `api/schema_util.php` | помощники по схеме (в т.ч. `psy_schema_once` — ALTER раз в час). |
| `api/status.php` | как библиотека: `status_get_row()`, `status_quick_replies()` (пара пресетов с запасными «👍 Ок» / «Отвечу позже 🙏»). |

Шаблон «файл-и-как-библиотека, и-как-эндпоинт»:
`if (realpath($_SERVER['SCRIPT_FILENAME']) === realpath(__FILE__)) { ...эндпоинт... }`
(так сделаны `status.php`, `reminders.php`, `storage_cleanup.php`). Missing-файл в
`require` — фатал, не ловится `catch(Exception)`: оборачивай в `@file_exists()`
и лови `\Throwable`.

## Пуш-уведомления
- `api/push.php` — подписка, отправка, `action=pending` (SW тянет текст),
  `action=poke` (отправитель дёргает после сообщения; тут же хук автоответа).
  Пачки — `pushSendMany` (curl_multi), `push_send_to_user`, `push_notify_group`.
- `sw.js` — service worker (версия `psy-vN`, поднимать при правке). Кнопки
  быстрого ответа в уведомлении строит из `d.quick_replies`; `swSendQuickReply`
  шлёт ответ без открытия приложения. Инлайн-ввод текста в вебе невозможен
  (только натив) — не возвращать «кнопку Ответить», которая просто открывает чат.

## Хранилище / обслуживание
- `api/storage_cleanup.php` — ретеншн файлов (`media_retention_days`, дефолт 365),
  чистка истёкших историй, удаление по refcount (`psyFileRefCount`), чтобы не
  ломать пересланные/расшаренные файлы.

## Платежи и выплаты
- Приём: `api/robokassa.php` (+ `-success`/`-fail`), альтернативы — `yookassa.php`,
  `sber_acquiring.php`, `payment_mock.php`. Ключи — в `*_config.php` вне git.
- Выплаты: `api/payouts.php` + проверка НПД (`npd_lib.php`). Схема (Robokassa
  Онлайн как касса-агент, выплаты вручную с р/с, чеки НПД на стороне психолога) —
  зафиксирована в CLAUDE.md.

## Отложено до переезда на VDS (не начинать без подтверждения)
Security-хардненинг (заголовки/CORS/IP-блок/скрытие текста в пушах), Cloudflare
против DDoS, E2E-шифрование диалогов, инфра под масштаб (VPS/managed MySQL/
объектное хранилище, уменьшение лимита загрузки 1 ГБ + сжатие картинок,
ограничение AI SSE-воркеров).
