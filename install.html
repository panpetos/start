📲 Установить приложение

psytalk работает как обычное приложение: открывается с домашнего экрана без адресной строки, а уведомления о сообщениях приходят, даже когда оно закрыто. Внутри — весь сервис: чаты, записи, каналы, лента и настройки, а не только переписка.

Состояние на этом устройстве

Проверяем…

🤖 Android

В Chrome установка делается одной кнопкой. Если кнопка неактивна — значит браузер уже считает приложение установленным либо вы открыли страницу не в Chrome (в Firefox и Opera установка есть, но называется по-своему).
  1. Откройте psytalk.pro в Chrome (в других браузерах пункт называется иначе или его нет).
  2. Нажмите ⋮ — три точки справа сверху.
  3. Выберите «Установить приложение». Если такого пункта нет — «Добавить на главный экран», а в нём «Установить».
  4. Откройте появившуюся иконку psytalk — именно её, а не закладку браузера.
Пункта «Установить приложение» нет вообще
  • Оно уже установлено. Chrome не предлагает установку второй раз. Проверьте, нет ли иконки psytalk на рабочем столе или в списке приложений — и откройте её. Если иконки нет, а пункт всё равно не появляется: Chrome → ⋮ → Настройки → Настройки сайтов → Все сайты → psytalk.pro → «Удалить данные», затем откройте сайт заново.
  • Открыто не в Chrome. В Samsung Internet это ⋮ → «Добавить страницу» → «На главный экран», в Firefox — ⋮ → «Установить».
  • Экономия трафика или режим инкогнито — в них установка недоступна.

🍏 iPhone и iPad

Apple не даёт браузеру кнопку установки — добавлять нужно вручную, и только из Safari. В Chrome на iPhone этого пункта нет. Это же условие касается уведомлений: Apple разрешает их только приложению с домашнего экрана, в обычной вкладке их не будет вовсе.
  1. Откройте psytalk.pro в Safari.
  2. Нажмите «Поделиться» — внизу по центру (на iPad — сверху справа).
  3. Пролистайте список и выберите «На экран „Домой“».
  4. Нажмите «Добавить». На экране появится иконка psytalk.
  5. Откройте приложение с иконки и включите уведомления — раздел ниже.
Как убедиться, что это приложение, а не закладка

Откройте иконку: адресной строки и кнопок Safari быть не должно. Если они видны — iOS сохранил обычную закладку, уведомлений в таком виде не будет. Удерживайте иконку → «Удалить закладку» и добавьте заново по шагам выше.

🔔 Уведомления на этом устройстве проверяем…

Подписка привязана к конкретной установке, поэтому включить нужно в каждом приложении отдельно — и на телефоне, и на планшете, и в браузере на компьютере. «Проверить» отправляет настоящее уведомление через сервер, а не рисует его на месте.
Все уведомления
Уведомление «отправлено», но не пришло
  • Смотрите строку «Воркер получал пуш» выше. Если там «не получал» — сообщение до телефона не дошло, и дело не в сайте: чаще всего это включённый VPN (он рвёт связь с сервисом доставки Google), режим энергосбережения или ограничения производителя.
  • Xiaomi, Redmi, POCO: Настройки → Приложения → Chrome (или psytalk) → Экономия батареи → «Нет ограничений», и там же включите «Автозапуск». Без этого MIUI глушит доставку в фоне.
  • Huawei, Honor: Настройки → Батарея → Запуск приложений → Chrome → управлять вручную, все переключатели включить.
  • Samsung: Настройки → Батарея → Ограничения в фоне → убрать Chrome из «Спящих приложений».
  • Проверьте, что уведомления Chrome не выключены на уровне системы: Настройки → Уведомления → Chrome.
Кнопка ничего не делает — что это значит
  • Разрешение уже было запрещено — второй раз браузер не спрашивает. iPhone: Настройки → Уведомления → psytalk → включить. Android: Chrome → ⋮ → Настройки → Уведомления → Настройки сайтов → psytalk.pro → разрешить.
  • На iPhone приложение открыто не с домашнего экрана — сначала добавьте его туда.

🤖 Android: включить уведомления полностью

На Android мало нажать «Разрешить» в браузере: система отдельно решает, показывать ли баннер поверх экрана, пускать ли уведомления на экран блокировки и не усыпить ли приложение ради экономии батареи. Пройдите три шага — это одна минута, и потом уведомления приходят как в мессенджере.
Шаг 1. Разрешение в самом приложении
  1. Откройте psytalk с иконки на рабочем столе (не вкладку браузера).
  2. Нажмите «Подключить это устройство» в разделе выше и в окне системы — «Разрешить».
  3. Нажмите «Проверить». Пришло уведомление — шаг 1 готов.
Шаг 2. Разрешения в настройках телефона
  1. Задержите палец на иконке psytalk на рабочем столе → «О приложении» (кружок с буквой i). Если приложение не устанавливали — то же самое сделайте с Chrome: уведомления идут через него.
  2. Разрешения → Уведомления → включить. Внутри включите все категории, какие там есть, — иначе часть сообщений телефон покажет молча.
  3. В том же разделе «Уведомления» включите:
    • Всплывающие уведомления (баннер поверх экрана) — иначе сообщение появится только в шторке, и вы его не заметите;
    • Показывать на экране блокировки — включая содержание, если хотите видеть текст, не разблокируя телефон;
    • Звук и значок на иконке (точка или число).
  4. Вернитесь в «О приложении» → Батарея (или «Использование батареи») → выбрать «Без ограничений». Это главный пункт: в режиме экономии Android придерживает доставку и уведомление приходит через час — или не приходит вовсе.
Шаг 3. Что ещё может глушить
  1. Режим «Не беспокоить» и «Фокусировка»: добавьте psytalk (или Chrome) в исключения, иначе уведомления придут беззвучно.
  2. VPN. Сервис доставки уведомлений Google через некоторые VPN не работает вовсе. Если уведомления не идут — попробуйте выключить VPN и нажать «Проверить».
  3. Экономия трафика в настройках сети: разрешите psytalk работать в фоне.
Xiaomi, Redmi, POCO (MIUI / HyperOS)
  • Настройки → Приложения → Все приложения → psytalk (или Chrome) → Автозапуск — включить. Без этого MIUI выгружает приложение и доставка прекращается.
  • Там же → Экономия заряда батареи → «Без ограничений».
  • Настройки → Уведомления → psytalk → «Плавающие уведомления» и «Уведомления на заблокированном экране» — включить.
  • Заблокируйте приложение в списке недавних (потяните карточку вниз → замок) — тогда очистка памяти его не закроет.
Samsung (One UI)
  • Настройки → Батарея и уход за устройством → Батарея → Ограничения в фоне → убрать psytalk / Chrome из «Спящих» и «Глубоко спящих» приложений.
  • Настройки → Уведомления → Дополнительные настройки → «Всплывающие уведомления».
Huawei, Honor
  • Настройки → Батарея → Запуск приложений → psytalk / Chrome → переключить на «Управлять вручную» и включить все три пункта (автозапуск, косвенный запуск, работа в фоне).
Realme, OPPO, vivo, OnePlus
  • Настройки → Батарея → Оптимизация энергопотребления → psytalk / Chrome → «Не оптимизировать».
  • Настройки → Приложения → psytalk → «Разрешить фоновую активность».
Ничего не помогло? Уведомления можно получать в Telegram, MAX или на почту — выберите способ в настройках уведомлений. Это работает независимо от настроек телефона.

♻️ Переустановить

Если приложение открывается «старым» — не появились новые разделы, висит прежнее меню, — дело не в иконке: оболочка и её кэш живут отдельно и удаление иконки их не трогает. Поэтому сначала сбросьте оболочку кнопкой ниже, и только потом, если нужно, удаляйте и добавляйте иконку заново. Вход в аккаунт и переписка не пострадают.
Как удалить иконку
  • iPhone: удерживайте иконку → «Удалить закладку» → «Удалить». Затем добавьте заново по шагам из раздела про iPhone.
  • Android: удерживайте иконку → «Удалить» (или перетащите в «Удалить»). Затем Chrome → ⋮ → «Установить приложение».
  • Полная чистка на Android (если и после сброса старый вид): Chrome → ⋮ → Настройки → Настройки сайтов → Все сайты → psytalk.pro → «Удалить данные».
